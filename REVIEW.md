### Examined and confirmed not a defect
1. **Truncation of timestamps to whole seconds before computation (`truncate_to_second`)**:
   Examined whether sub-second precision should be retained. Rule R1 explicitly mandates: "Before any calculation, instants are truncated to whole seconds (09:40:00.900 counts as 09:40:00), and the truncated value is what is stored and returned." Thus, zeroing out microseconds upon boundary conversion is required by contract.
2. **Standard Competition Ranking in Leaderboard (`1, 2, 2, 4`)**:
   Examined whether dense ranking (`1, 2, 2, 3`) or array index was expected. R6/Contract specifies standard competition ranking where tied entries share the same rank and subsequent ranks are skipped. This was verified and correctly mapped to MongoDB `$rank`.
3. **Optimistic Locking via History in Regularization**:
   Examined whether MongoDB transactions were required for `PATCH`. MongoDB single-document updates are ACID-compliant; asserting document state or history array length in `update_one` provides atomic compare-and-swap without multi-document transaction overhead.
